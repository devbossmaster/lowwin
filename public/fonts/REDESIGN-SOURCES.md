# Font sources

DM Sans Latin 400/500/600/700 WOFF2 files are copied from the installed, pinned @fontsource/dm-sans 5.2.8 package. License: DM-Sans-LICENSE.txt (SIL Open Font License).

Noto Sans Ethiopic variable WOFF2 is the official Google Fonts Ethiopic subset, retrieved 2026-10-22 from https://fonts.gstatic.com/s/notosansethiopic/v50/7cHAv50vjIepfJVOZZgcpQ5B9FBTH9KGNfhSTgtoow1KVnIv4gckut2Q.woff2 via the Google Fonts CSS2 API. It supplies regular through bold from one locally served variable font. License: NotoSansEthiopic-LICENSE.txt.

There are no runtime Google Fonts requests. Font files use font-display:swap and the Ethiopic face has a unicode-range.

Poppins, weights 400, 500, 600 and 700, Latin WOFF2 subsets.

Original typeface: https://github.com/itfoundry/Poppins
Google Fonts family: https://github.com/google/fonts/tree/main/ofl/poppins
License: SIL Open Font License 1.1, included in Poppins-OFL.txt.

The WOFF2 subsets were reused from the existing local GojoGames checkout's
Fontsource Poppins assets. Amharic uses the existing Lowwin Ethiopic font.
All font files are served locally; no runtime Google Fonts request is made.
